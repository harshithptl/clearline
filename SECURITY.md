# Security

Clearline is a personal portfolio project, not production financial software.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting (Security tab, "Report a vulnerability") rather than a public issue.

## Scope notes

- Credentials in this repo (`clearline:clearline`) are for the local Docker Compose stack only.
- The order gateway has no authentication and is meant for local use. The public demo exposes only read-only endpoints (SPEC 2.2).
